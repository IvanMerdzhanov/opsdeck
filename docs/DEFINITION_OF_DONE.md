# Definition of Done

- [ ] Acceptance criteria met and demoed to the requester
- [ ] Unit tests for new logic; `npm test` and `npm run lint` pass
- [ ] If the event flow changed, `scripts/smoke.sh` passes against the compose stack
- [ ] API change? `docs/openapi.yaml` updated
- [ ] New config or env var documented in `.env.example` and the README
- [ ] Health/readiness probes still accurate; errors logged with context
- [ ] Architectural decision? An ADR is written
